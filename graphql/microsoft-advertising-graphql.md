# Microsoft Advertising GraphQL API

Microsoft Advertising (Bing Ads) API covers campaign management, ad groups, keywords, audiences, bid strategies, extensions, reporting, and bulk operations for search and audience advertising.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Microsoft Advertising REST API
**Documentation:** https://learn.microsoft.com/en-us/advertising/

- Reference: https://learn.microsoft.com/en-us/advertising/campaign-management-service/campaign-management-service-reference
- Schema: https://github.com/api-evangelist/microsoft-advertising
